Sunfish 4KB micro chess engine built for the [make.fun tiny-chess-01](https://make.fun/bounty/tiny-chess-01) bounty.
- Negamax search with Alpha-Beta pruning & Quiescence Search
- Piece-Square Tables (PST) positional evaluation
- Strict node budget per move for 100% deterministic replay
